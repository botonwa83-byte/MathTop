# 年龄分级问卷（Age Rating）

> 位置：App Store Connect → App 信息 → 年龄分级 → 编辑。
> 本应用为数学学习工具，无暴力、成人内容、博彩或不受限制网络访问。建议结论：4+。

---

## 逐项答案

| 问题项 | 答案 |
|--------|------|
| 卡通或幻想暴力 | 无 |
| 现实暴力 | 无 |
| 露骨/恐怖暴力 | 无 |
| 亵渎或低俗幽默 | 无 |
| 成人/性暗示题材 | 无 |
| 裸露 | 无 |
| 色情内容 | 无 |
| 恐怖/惊悚题材 | 无 |
| 酒精、烟草或毒品的使用或相关内容 | 无 |
| 模拟赌博 | 无 |
| 医疗/治疗信息 | 无 |
| 不受限制的网络访问 | 否 |
| 赌博与竞赛 | 无 |

## 其它分级相关开关

- 是否含用户生成内容（UGC）：否（无评论、上传、社交功能）。
- 是否为 Kids Category：否（面向初高中学习用户，且含内购，不建议放入儿童类别）。
- 不受限制 Web 访问：否（App 不内嵌浏览器；若后续加外链，需仅链接隐私/支持页面并使用系统浏览器）。
- 广告：无。

最终年龄分级：**4+**
